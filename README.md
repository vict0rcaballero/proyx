---

## 📖 Descripción general

**Proyx** es una demostración de desarrollo web sobre la plataforma WordPress. Este repositorio sirve para documentar y hacer seguimiento a las configuraciones, temas y plugins personalizados utilizados en el entorno de pruebas, manteniendo un historial limpio mediante Git.

## ✨ Características destacadas

* 🛠️ **Arquitectura de Pruebas:** Entorno aislado para probar nuevas implementaciones sin afectar sitios en vivo.
* 🎨 **Desarrollo Modular:** Seguimiento específico de la carpeta `wp-content` (temas y plugins).
* 🔄 **Versionado Activo:** Control de cambios paso a paso desde el inicio del proyecto.

## ⚙️ Estructura del repositorio

Para mantener el repositorio optimizado, los archivos del núcleo (core) de WordPress suelen ser ignorados. El desarrollo se concentra principalmente en:

* 📂 `/wp-content/themes/` - Archivos de diseño y plantillas.
* 📂 `/wp-content/plugins/` - Lógica personalizada y extensiones.
